# VideoStudio

Видеостудия с подходом **human+AI**: основную работу по сборке видео (сцены, слои, нарезка,
наложения, эффекты) делает ИИ, человек правит и утверждает.

Проект — **форк движка презентаций**: переиспользует его таймлайн, медиа-библиотеку, движок
воспроизведения, систему тем и конвейер рендера. Единица контента эволюционирует от *слайда*
к *сцене-композиции из слоёв* (видео/картинка/текст/компонент, с трансформами и эффектами).

> 🎯 **План развития — [`docs/ROADMAP.md`](docs/ROADMAP.md).** Там описано, что делаем и в каком
> порядке: обобщение слайда до слоя, сплит-скрин, видео-на-видео, эффекты, ИИ-авторинг, рендер v2.

## Стек

| Слой | Технология | Порт (dev) |
|------|-----------|-----------|
| БД | PostgreSQL | `5437` |
| Backend | FastAPI (Python) | `8002` |
| Frontend | Vue 3 + Vite + Tailwind | `5175` |

## Запуск

```bash
docker compose up -d          # или ./start.sh
# frontend: http://localhost:5175
# API:      http://localhost:8002
./stop.sh                     # остановить
```

Compose-проект `videostudio-saas`, БД `videostudio_db`. При первом старте схема поднимается из
`init/`; рабочая БД форка — отдельная копия (том `videostudio_postgres_data`).

## Статус

Унаследованный движок презентаций работает как есть; идёт планомерный переход к сценам/слоям
(см. роадмап). Код и БД пока используют имена `presentations`/`slides` — их переименование
запланировано отдельной фазой.
